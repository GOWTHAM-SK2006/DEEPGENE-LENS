2. FASTA Analysis Workflow
--------------------------

1. User selects a .fasta, .fa, or .fna file.
2. React sends the file as multipart FormData.
3. FastAPI receives and validates the file.
4. Biopython SeqIO parses all FASTA records.
5. DNA characters are validated.
6. The backend calculates sequence IDs, lengths, total bases, A/T/G/C
   composition, per-sequence GC content, overall GC content, and invalid
   base count.
7. JSON results are returned to React.
8. React displays the analysis dashboard.

Source files:
- frontend/src/App.jsx
- frontend/src/styles.css
- backend/app/bioinformatics/fasta.py
- backend/app/routes/uploads.py

---------------------------

- NCBI RefSeq viral complete genomes

  txid10239[Organism] AND refseq[filter] AND "complete genome"[Title]

5. Real 1D-CNN
--------------

Source files:
- backend/app/models/cnn.py
- backend/app/models/train_cnn.py

Implementation:
- PyTorch 1D-CNN
- One-hot A/C/G/T encoding
- Conv1D layers with 32, 64, and 128 filters
- Max pooling and adaptive max pooling
- Dropout classifier
- 12 viral-family classes

Preprocessing:
- Maximum length: 4,096 bases
- Longer sequences are truncated.
- Shorter sequences are zero-padded.
- Training and inference share the same encoder.
- Invalid sequences are rejected.

Training configuration:
- Epochs: 12
- Batch size: 8
- Optimizer: Adam
- Learning rate: 0.001
- Class-weighted cross-entropy
- CPU training completed

Model files:
- artifacts/viral_family_cnn.pt
- artifacts/viral_family_cnn.metrics.json

7. Prediction API
-----------------

Endpoint:
- POST /api/analysis/predict

Input:
- Multipart FASTA file
- Supported extensions: .fasta, .fa, .fna

Processing:
1. Validate extension.
2. Parse FASTA with Biopython.
3. Reject characters outside A, T, G, and C.
4. Load the saved PyTorch checkpoint.
5. Apply the saved 4,096-base preprocessing.
6. Run inference.
7. Return prediction for every sequence.

Response includes:
- Sequence ID
- Predicted viral family
- Confidence from model softmax probability
- Model metadata
- research_only = true

Error handling:
- Invalid DNA: HTTP 422
- Missing model: HTTP 503
- Unsupported extension: HTTP 415
